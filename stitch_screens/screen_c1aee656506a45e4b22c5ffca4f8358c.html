# E-commerce Management System PRD ## Core Requirements - **Layout**: Left-hand sidebar navigation, top-bar for breadcrumbs/user profile, and main content area. - **Login**: Dual-role Tab (Admin/User), brand area, and login form. - **Dashboard**: Stats cards (Revenue, Orders, etc.) and quick actions. - **Site List**: Search, 4-step pipeline indicators, and action buttons. - **Product Source**: 4 Tabs (Walmart, Amazon, TikTok, Hot Products), data table, and pagination. - **WooCommerce Integration**: Site selection, sync status, and product table. - **Feed Generation**: Multi-site selection and feed product management. - **Brand Kit**: List view + 6 Detail Tabs (Info, Store, Footer, Tax, Fingerprint, Google). - **Google MC**: Automated data table for Merchant Center. - **User Management**: CRUD table for user administration. - **System Settings**: 7 Tabs (WP, 1Panel, DeepSeek, Crawlbase, Cloudflare, Google, Fingerprint). - **Modals**: Wizard, Edit, Confirm, Import, Logs. - **Global UI**: Toast, Status bar, Skeleton screens, Empty states. - **Design Spec**: Consistent color variables, spacing, radius, shadows, and font scale.
